# Mento Tech

### 🤔 | O que é?
A MentoTech é uma plataforma gratuita desenvolvida com o objetivo de conectar mentores e mentorados na área de tecnologia. Através dela, é possível compartilhar conhecimento, promover aprendizado colaborativo e fortalecer a comunidade tech.

### 💻 | Funcionalidades
- Cadastro de usuários (mentores e mentorados)
- Sistema de busca por mentores ou visualizar todos que estão cadastrados na plataforma
- Agendamento de sessões de mentorias
- Página de pagamento para adquirir um plano
- Formulário de contato

### ⚒️ | Tecnologias Utilizadas
- <b>ReactJS</b>: Framework front-end para construção da plataforma.
- <b>CSS</b>: Estilização das páginas.
- <b>Figma</b>: Idealização dos protótipos de alta fidelidade
- <b>Vercel</b>: Hospedagem do projeto em um site.
- <b>Azure DevOps</b>: Controle e gerenciamento do projeto.
